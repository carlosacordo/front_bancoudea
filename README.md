# Front Bancoudea

Proyecto Next.js con estructura de Atomic Design.

## Estructura de carpetas

- `components/atoms`  - Componentes más pequeños (botones, inputs, etc.).
- `components/molecules` - Combinaciones de átomos.
- `components/organisms` - Bloques complejos reutilizables.
- `components/templates` - Layouts y plantillas de página.
- `pages` - Rutas de Next.js.

## Scripts

```bash
npm install
npm run dev     # iniciar servidor de desarrollo
npm run build   # compilar para producción
npm run start   # iniciar app en producción
```
